# Agent Note: 中文主语料与外部历史

Status: implemented

## Problem

研究分支从产品仓库提取后仍携带数百组双语文件和冻结 archive。它们显著增加文件数量、维护门禁和检索噪声，也让已经删除的产品实现继续表现为当前权威。

## Decision

活跃研究文档和 Agent Note 只维护中文主文件。Skill、提示词、协议样例或校准资料只有在英文直接影响模型或工具行为时保留英文，并在语料清单中标记为 `execution-language`。

冻结 archive 和没有当前研究价值的产品记录退出工作树。R0 的 source lock、提取提交、Git 历史和固定到官方源码提交的链接共同承担恢复与追溯；研究导航不复制完整历史正文。

R2 语料清单把每份保留的 Note、文档、Skill 和脚本归为方法、可复用工具、案例、历史证据或治理。没有分类的活跃文件不能通过 R2 验收。

## Alternatives considered

**继续维护完整双语。** 它保留官方仓库的对称结构，但让每次语料调整都产生三文件变更，与研究分支减少数量和中文使用场景冲突。

**只保留英文。** 它更接近官方来源，却把日常研究和治理成本转移给中文使用者；官方英文已经可以通过固定来源链接读取。

**在工作树永久保留 archive。** 它提供离线历史，但冻结内容不能整理，且多数记录只解释已经删除的产品实现。Git 和 source lock 能以更低常驻成本恢复相同证据。

## Consequences

研究者默认只编辑一个中文文件。翻译工具保留的英文属于行为输入或研究样本，不代表仓库恢复双语政策。

删除内容仍可精确恢复，但离线 checkout 不再包含全部产品历史。任何重新引入都必须说明独立研究价值，不能仅以“官方仓库曾经存在”为理由。
