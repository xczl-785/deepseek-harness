# Research extraction

English | [中文](README.zh.md)

This directory owns the conversion of `research/dsh-development-harness` from the DeepSeek Harness product monorepo into an independent development-harness research repository.

- [`source-lock.json`](source-lock.json) records the immutable extraction source, product source, and measured baseline.
- [`extraction-manifest.json`](extraction-manifest.json) gives every tracked top-level path an R1 disposition.
- The [research repository charter](../.agents/notes/proposed/process/2026-08-15-development-harness-research-repository-charter.md) defines the target repository, result waves, constraints, and acceptance criteria.

The manifest controls extraction work. A deletion target is not permission to remove unique research evidence. Exceptions must identify the research question and retain only the smallest useful case material.
